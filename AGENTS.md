# Instruções do projeto

Este projeto implementa a prova de Programação para Dispositivos Móveis. Consulte `docs/requisitos.md` para os requisitos e `docs/entrega.md` para documentação e avaliação. O tema escolhido é **O que eu leio agora?**

Ao implementar ou revisar este trabalho, consulte também `.agents/skills/lume-prova/SKILL.md`. Preserve a distinção entre requisitos do enunciado, sugestões e decisões ainda não tomadas. Não leia nem altere arquivos README; a documentação de contexto do projeto está em `docs/`.

Para exemplos de implementação, consulte a skill correspondente em `.agents/skills/`: `lume-telas-rotas` para telas e navegação, `lume-api-dados` para API e persistência, e `lume-css` para estilos. Os exemplos são orientações a adaptar, não arquivos já implementados. As mesmas skills também estão em `.claude/skills/` para o Claude; mantenha ambas as cópias sincronizadas.
